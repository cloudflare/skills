# Set Up a Worker

1. Read [Wrangler](../wrangler/SKILL.md), resolving the path relative to this skill file, and follow its project inspection and configuration guidance.
2. For a new Worker, fetch and follow the [CLI getting-started guide](https://developers.cloudflare.com/workers/get-started/guide/). For a framework project, select and fetch its [framework guide](https://developers.cloudflare.com/workers/framework-guides/).
3. Use the existing project's scripts and configuration when present. Complete the requested setup and local development checks using the Wrangler skill; deploy only when deployment is part of the user's request.
4. Report the project location, how to run it locally, checks performed, and any missing prerequisites.
